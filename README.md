# Asansörde Yanlış Kata Basma Vicdanı

Bu depo, insanlığın en sessiz felaketini belgeler: **asansörde yanlış kata basmak**.

Proje bilimseldir. Proje sanattır. Proje evde unutulan evrakın üst kata çıkmasıdır.

## Ne işe yarar?

Çalışır. Gerçekten çalışır. Bir hedef kat seçer (veya sen verirsin), sonra **bilerek başka bir kata basar** ve seni resmi bir pişmanlık törenine sokar.

```bash
python3 vicdan.py
python3 vicdan.py 7
```

Çıktı örneği (hayatın kendisi):

```
=== TENTI AŞ ASANSÖR VICDAN PROTOKOLÜ v0.7 ===
Hedef kat: 7
...parmak yaklaşıyor...
BASILAN KAT: 16
```

## Kurulum

1. Python 3 al.
2. Bu repoyu klonla.
3. Asansöre binme. Önce kodu çalıştır. Hazırlıklı ol.

Bağımlılık yoktur. Vicdan standart kütüphanedir.

## Sıkça sorulmayan sorular

- **13. kat neden yok?** Çünkü 13. kat zaten vicdansız.
- **Bu bir çerçeve mi?** Hayır. Bu bir asansör.
- **Üretim ortamında kullanabilir miyim?** Kullanma. Asansörü kızdirma.

## Katkıda bulunmak

Yanlış kata bas, issue aç, pull request gönder. Doğru kata basarsan PR reddedilir.

## Lisans

Kapı açık kalsın lisansı. İnsanlar binsin. Kimse konuşmasın.
